Packages

VX3 is a turborepo monorepo containing multiple packages.

@nk4dev/vx

The core SDK package. Includes the CLI tool (vx3), RPC helpers, payment module, gas utilities, contract tools, and the local dev server.

v0.0.18
TypeScript ethers.js v6 MIT

packages/template

Project scaffolding template used by vx3 create. Contains Solidity samples (sample.sol, contracts/Sample.sol), JavaScript examples, and vmx.config.json.

template

packages/hardhat

Hardhat integration files scaffolded by vx3 setup hardhat. Provides config, compile scripts, test setup, and deployment scripts.

tooling

packages/system

System-level utilities and global configuration module used internally by the VX3 monorepo.

internal

Monorepo Structure

Directory Layout

vx3-master-repo/
├── vx/                    # Core SDK (@nk4dev/vx)
│   ├── src/
│   │   ├── cli.ts         # CLI entry point
│   │   ├── index.ts       # Library entry point
│   │   ├── command/       # CLI commands (create, gas, pay, rpc, serve, setup)
│   │   ├── core/          # RPC, contract, data helpers
│   │   ├── payment/       # Payment module
│   │   ├── server/        # Local dev server
│   │   └── types/         # TypeScript types
│   ├── packages/
│   │   ├── template/      # Project template files
│   │   └── hardhat/       # Hardhat setup files
│   └── docs/              # SDK-specific docs
├── packages/
│   └── system/            # System utilities
└── docs/                  # This documentation site

Development Scripts

Script Description
npm run dev Start all packages in dev mode (turbo)
npm run build Build all packages
npm run dev:sdk Dev mode for SDK only
npm run dev:web Dev mode for web app
npm run dev:server Dev mode for server
npm run db:push Push database schema
npm run db:studio Open database studio
