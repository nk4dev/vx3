CLI Reference

All commands available via the vx3 CLI.

Command Description
vx3 create <name> Scaffold a new Web3 project from the built-in template. Copies Solidity samples, configs, and generates package.json.
vx3 serve --debug Start a local development server. The --debug flag enables a TailwindCSS-powered dashboard at /debug showing block number and API links.
vx3 gas Check gas fees on the connected chain. Outputs gasPrice, maxFeePerGas, and maxPriorityFeePerGas in both wei and gwei.
vx3 rpc init Generate an RPC configuration template (vx.config.json). Default: [{"host":"localhost","port":8575,"protocol":"http"}]
vx3 setup hardhat Scaffold Hardhat configuration files into the current project for compiling, testing, and deploying smart contracts.
vx3 pay <to> <amount> Send an ETH payment. Uses $PRIVATE_KEY env var. Optional --rpc flag to specify endpoint.

RPC Configuration

The vx3 rpc init command generates a vx.config.json file:

[
  { "host": "localhost", "port": 8575, "protocol": "http" }
]

The loader uses the first object in the array. A single-object format may be standardized in a future release.
