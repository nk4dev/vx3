Features

Everything you need for Web3 development in one toolkit.

🔗

Multi-Chain Support

Connect to Ethereum mainnet, testnets, or local nodes via ethers.js v6. Configure RPC endpoints with vx.config.json.

💳

Payment Module

Send ETH payments programmatically or via CLI. Simple API: vx.payment.sendPayment(). Supports custom RPC and amount in ETH.

⚡

No SaaS Fee

No connection required to external APIs. Direct RPC access with zero middleware costs. You own your infrastructure.

🛠️

CLI Toolkit

Create projects, check gas, manage RPC configs, deploy contracts — all from the vx3 command line.

📦

Project Templates

Scaffold new Web3 projects instantly with vx3 create. Includes Solidity samples, config files, and contract examples.

🔨

Hardhat Integration

Built-in Hardhat setup with vx3 setup hardhat. Compile, test, and deploy smart contracts seamlessly.

🖥️

Debug Dashboard

Local dev server with TailwindCSS-powered debug UI. Shows block number, server host, and quick API links.

⛽

Gas Monitoring

Check gas fees in real-time with vx3 gas. Displays gasPrice, maxFeePerGas, and maxPriorityFeePerGas in gwei.
