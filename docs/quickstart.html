Quick Start

Get up and running with VX3 in under a minute.

1

Install the SDK

npm i @nk4dev/vx
# or install globally
npm i -g @nk4dev/vx

For one-off usage: npx vx3 <command>

2

Create a new project

# Interactive prompt
vx3 create

# Or specify project name directly
vx3 create my-app

Copies template files including Solidity samples, config, and package.json.

3

Initialize RPC config

vx3 rpc init

Creates vx.config.json with your RPC endpoint settings.

4

Start the dev server

vx3 serve --debug

Launches a local server with a debug dashboard at /debug.

5

(Optional) Setup Hardhat

vx3 setup hardhat

Scaffolds Hardhat config files for compiling and deploying contracts.

Prerequisites

  • Node.js v18+ (required for built-in fetch)
  • npm / pnpm / yarn
  • MetaMask or other Web3 wallet
